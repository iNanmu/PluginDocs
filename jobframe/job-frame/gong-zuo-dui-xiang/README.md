# 工作对象

## 介绍

即在服务器上任意地图位置上出现的工作对象，对象设置、数据来自于所属的工作组，工作对象分为 **持久对象、临时对象** 这两个类型的对象区别在于 **临时对象会在服务器重启后消失** 数据也不会保存，而 **持久对象会将对象数据等储存至服务器** 内在下次服务器启动时加载出来

## 对象生成

对象生成通过 **/frame create \[工作组] \[类型]&#x20;**<mark style="color:green;">**\[是否为持久对象] \[生成的位置]**</mark> 命令进行生成，对象类型分为 **ENTITY、BLOCK** 类型，这两种类型都是通过 **向客户端发送数据包** 生成实体、方块，能很好的降低生成实体、方块所造成的消耗，避免卡顿，这两种类型的基础设置均可在工作组配置内进行预先设置
