# ❌ 旧授权系统

## 群命令

| 命令                                       | 说明                                 |
| ---------------------------------------- | ---------------------------------- |
| /key update-ip **\[插件名] \[授权码]** 0.0.0.0 | 修改授权码IP \[建议修改为 0.0.0.0 会**自动绑定**] |
| /key update-port **\[插件名] \[授权码] \[端口]** | 修改授权码端口 \[可使用 ',' 隔开]              |
| /key look-self                           | 在对应售后群查看授权码                        |
| /key get-plugin                          | 在对应售后群构建插件                         |

## 授权码说明

授权码默认IP绑定 **0.0.0.0** 当授权码IP为 **0.0.0.0** 时，在服务器加载插件时会 **自动绑定本地IP地址，同时端口限制**，每个授权码默认只支持绑定同IP下 **2** 个服务器端口，独立机可免费升为 **IP绑定类授权码(无端口限制但不可随时更改授权码绑定信息)**

端口绑定修改请在售后群使用 **/key update-port** 命令修改

## 注意事项

如果你服务器安装了 **YUM** 插件，请删除，或者关闭 **YUM** 网络屏蔽功能
