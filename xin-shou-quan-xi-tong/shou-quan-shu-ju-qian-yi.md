# ⚙️ 授权数据迁移

## 数据迁移

主要是给旧授权系统用户将授权数据迁移至新系统，所以没购买过授权的用户可以不用看，旧系统授权迁移至新版会有授权时效补偿与端口上限补偿

## 迁移步骤

* 1\. 售后群中输入 **#数据迁移** 后可查看你的QQ用户可迁移的授权数据
* 2\. 查看到可迁移的授权数据后使用在售后群内输入 **#数据迁移<换行>授权码** 命令即可迁移

授权码迁移后就会发放授权时效补偿等内容，具体补偿内容如下

* JobFrame — 365 天 + (随机30\~365天) + (2\~4自动绑定端口)
* TalentAttribute — 365 天 + (随机30\~365天) + (2\~4自动绑定端口)
* RefinePlus — 365 天 + (随机30\~365天) + (2\~4自动绑定端口)
* AttributeInventory — 365天 + (2\~4自动绑定端口)

注意授权数据8月1日后不迁移就无法使用授权码及云端加载服务，不进行授权数据迁移就不会有授权时效，等需要使用时再进行迁移即可
