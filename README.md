# AttributePlus

## 插件相关

| 说明    | 内容                 |
| ----- | ------------------ |
| 支持版本  | **1.8 \~ 1.21.11** |
| 插件软依赖 | MythicMobs         |
| 插件硬依赖 | **PlaceholderAPI** |

[「楠木的崽子们」](https://ersha.gitbook.io/code/zhi-shi-xing-qiu) 知识星球，获取更多 **DungeonPlus、AttributePlus** 插件附属，同时可获得星球分享的属性脚本、地牢模板配置等内容。

## 插件介绍

这是一款可扩展性很强的属性插件，插件拥有 40+ 种属性，多种条件判断，每种属性都可以设置 **优先级、战斗力、部分属性还支持自定义公式** 同时还提供了多种特色机制，所有的属性均支持 **小数点、负数、随机值** 包括附属插件所注册的新属性，同时属性还可以作用到怪物上。\
插件还提供 [**开发文档**](https://ersha.gitbook.io/attributeplus-pro/kai-fa-wen-dang) 你可以做出 **更多的属于自己服务器的属性及读取方式**

## 插件用法

> 下载 [**AttributePlus vPro**](https://www.mcbbs.net/thread-898670-1-1.html) ， **PlaceholderAPI** 插件，放入 **/plugin** 文件夹后重启服务器
