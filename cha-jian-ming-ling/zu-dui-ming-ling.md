# 组队命令

| 命令                           | 说明          |
| ---------------------------- | ----------- |
| team create                  | 创建队伍        |
| team disband                 | 解散队伍        |
| team quit                    | 退出队伍        |
| team kick **队员**             | 踢出队员        |
| team invite **玩家**           | 邀请一个玩家加入队伍  |
| team transfer **队员**         | 将队长转让其他队员   |
| team request join **玩家**     | 申请加入某个玩家的队伍 |
| team request accept **玩家**   | 同意某个玩家的入队申请 |
| team request unaccept **玩家** | 拒绝某个玩家的入队申请 |
