# 插件命令

## 注意事项

请给予玩家 **dungeon.user** 权限,不然玩家可能无法进行组队等操作，从 1.0.8 版本开始 start 命令权限调整为 **dungeon.start**

## 命令

> 以下命令包含 **\*** 为必输入,如果没有则可以忽略

| 命令                                         | 说明                                                                                            |
| ------------------------------------------ | --------------------------------------------------------------------------------------------- |
| **基础命令**                                   |                                                                                               |
| dp、dungeon、dungeonplus                     | 插件主命令                                                                                         |
| dp start <地牢> <参数1;参数2;...>                | 挑战(启动)地牢                                                                                      |
| dp leave                                   | 退出当前挑战的地牢                                                                                     |
| dp revive <玩家> <是否回到死亡点> <是否强行复活(无视次数)>    | 地牢内死亡复活                                                                                       |
| dp team                                    | [**队伍命令**](https://ersha.gitbook.io/dungeonplus/cha-jian-ming-ling/zu-dui-ming-ling) (快捷操作面板) |
| **脚本组命令**                                  |                                                                                               |
| dp script trigger <脚本&#x7EC4;**\***> <触发者> | 地牢脚本组触发命令                                                                                     |
| **地牢编辑命令**                                 |                                                                                               |
| dp editor                                  | 地牢编辑主命令                                                                                       |
| dp editor edit <地牢\*>                      | 编辑一个地牢                                                                                        |
| dp editor info <地牢\*>                      | 打开快捷编辑地牢面板                                                                                    |
| dp editor save <地牢\*>                      | 保存地牢                                                                                          |
| dp import <地牢\*>                           | 导入一个地牢(需将地图放入 **/map**)                                                                       |
