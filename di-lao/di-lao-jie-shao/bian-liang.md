# 变量

## 地牢变量

以下变量只有玩家在地牢内才会显示数据，如果不在地牢将返回 **\* 无数据 \***

| 变量                                | 说明                                                   |
| --------------------------------- | ---------------------------------------------------- |
| dungeon\_name                     | 获取当前地牢名                                              |
| dungeon\_uuid                     | 获取当前地牢UUID                                           |
| dungeon\_state                    | 获取当前地牢状态 **\[true=通关;false=未通关]**                    |
| dungeon\__death\__&#x73;tate      | 获取玩家死亡状态 **\[1=活着;2=死亡]**                            |
| dungeon\_player\_size             | 获取当前地牢队伍人数                                           |
| dungeon\__task\_state\__**<任务名>** | 获取当前地牢某个任务是否正在运行                                     |
| dungeon\_placeholder\_**<地牢占位符>** | 获取 [**地牢占位符**](../di-lao-zhan-wei-fu/) 数据信息,方便其他插件获取 |

## 队伍变量

以下变量不在地牢内也会生效，如果没有队伍的话返回 **无队伍**

| 变量                 | 说明                               |
| ------------------ | -------------------------------- |
| team\_uuid         | 获取当前队伍UUID                       |
| team\_leader       | 获取当前队伍队长名字                       |
| team\_is\_leader   | 获取自己是否为队长 **\[true=是;false=不是]** |
| team\_player\_size | 获取当前队伍人数                         |
