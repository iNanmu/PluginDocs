# Walk

## 脚本参数

标注 **\*** 为必填参数

| 参数             | 说明                 |
| -------------- | ------------------ |
| **level**      | 玩家等级要求             |
| **permission** | 玩家权限要求 ('none' 为无) |
| **location-a** | A点-方块位置(X,Y,Z)     |
| **location-b** | B点-方块位置,可不填(X,Y,Z) |

> 触发者 **死亡的玩家，**&#x5B58;在触发者的交互脚本可使用 **@self** 类型的地牢脚本

## 区域说明

当只设置了 **location-a** 时则经过该 **方块** 时就会触发\
如果同时设置了 **location-a、location-b** 时则经过两点的 **区域范围内** 时触发

## 提示

推荐在插件自带的 **在线编辑功能模式** 下用快捷方式设置交互脚本，这样子会方便很多出错的情况也会降低，当然你要是不嫌麻烦的话也可以在 **地牢交互脚本文件夹(dungeon/interact)** 内手动新建 **YML** 写交互脚本
