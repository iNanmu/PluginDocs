# Command

## 脚本参数

标注 **\*** 为必填参数

| 参数             | 说明                                 |
| -------------- | ---------------------------------- |
| **command \*** | 命令(模糊匹配,不需要加 '/' 同时可使用 '**,**' 隔开) |
| **cancel**     | 是否取消命令的执行                          |

> 触发者 **执行命令玩家，**&#x5B58;在触发者的交互脚本可使用 **@self** 类型的地牢脚本

## 提示

推荐在插件自带的 **在线编辑功能模式** 下用快捷方式设置交互脚本，这样子会方便很多出错的情况也会降低，当然你要是不嫌麻烦的话也可以在 **地牢交互脚本文件夹(dungeon/interact)** 内手动新建 **YML** 写交互脚本
