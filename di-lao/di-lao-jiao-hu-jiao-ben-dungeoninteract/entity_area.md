# Entity\_Area

## 脚本参数

标注 **\*** 为必填参数

| 参数                 | 说明                                     |
| ------------------ | -------------------------------------- |
| **\*area**         | 地牢区域名                                  |
| **\*entity-size**  | 区域实体数量满足时触发 (1)                        |
| **\*entity-name**  | 实体名称(模糊匹配 none 则无限制,可使用 ',' 隔开) (none) |
| **\*entity-clear** | 实体清除(true/false) (false)               |

> 触发者 **无**

## 提示

推荐在插件自带的 **在线编辑功能模式** 下用快捷方式设置交互脚本，这样子会方便很多出错的情况也会降低，当然你要是不嫌麻烦的话也可以在 **地牢交互脚本文件夹(dungeon/interact)** 内手动新建 **YML** 写交互脚本
