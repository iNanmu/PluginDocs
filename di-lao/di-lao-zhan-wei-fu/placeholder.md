# Placeholder ( SELF )

## 占位符介绍

因为部分脚本不支持 **PlaceholderAPI** 变量获取，所以才有了这个占位符，用这个占位符就可以在任何脚本上获取 **PlaceholderAPI** 变量但占位符只支持以 **@SELF /**  类型触发的脚本

## 占位符列表

| 占位符               | 说明 | 返回    |
| ----------------- | -- | ----- |
| \<placeholder:变量> | 内容 | 变量返回值 |

## 支持类型

* [ ] INIT
* [ ] SYSYEM
* [ ] DUNGEON
* [ ] PLAYER
* [x] SELF
