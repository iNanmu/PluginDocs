# If ( ALL )

## 占位符介绍

使用 JavaScript 语法判断表达式并返回不同内容，表达式可使用 **PlaceholderAPI** 及 **地牢占位符** 但需要注意的是不能再 if 内套 if 别作死，如果因为这个问题来问我你会被我"爱"一顿

## 占位符列表

| 占位符                           | 说明        | 返回  |
| ----------------------------- | --------- | --- |
| \<if:\[表达式] \*满足时返回 \*未满足时返回> | 判断表达式是否通过 | 所设值 |

> \<if:\[\<mob:kill-amount \*小白>>=10] \*已击杀10只 \*未击杀10只> — 返回 **已击杀10只/未击杀10只**
