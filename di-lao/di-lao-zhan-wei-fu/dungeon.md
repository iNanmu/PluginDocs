# Dungeon ( ALL )

## 占位符介绍

用于获取地牢名、地牢世界名、地牢启动参数的占位符

## 占位符列表

| 占位符                           | 说明         | 返回                                                                                               |
| ----------------------------- | ---------- | ------------------------------------------------------------------------------------------------ |
| \<dungeon:name>               | 获取当前地牢名    | 当前地牢名                                                                                            |
| \<dungeon:world-name>         | 获取当前世界名    | 当前世界名                                                                                            |
| \<dungeon:params \*参数位 \*默认值> | 获取对应地牢启动参数 | [**地牢启动参数**](https://ersha.gitbook.io/dungeonplus/di-lao/di-lao-jie-shao/di-lao-qi-dong-can-shu) |

## 支持类型

* [x] INIT
* [x] SYSYEM
* [x] DUNGEON
* [x] PLAYER
* [x] SELF
