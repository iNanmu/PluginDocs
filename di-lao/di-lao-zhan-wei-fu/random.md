# Random ( ALL )

## 占位符介绍

用于获取随机值 **最小值、最大值** 支持使用 **JavaScript** 公式

## 占位符列表

| 占位符                               | 说明               | 返回 |
| --------------------------------- | ---------------- | -- |
| \<random:value \*最小值 \*最大值>       | 获取随机值            | 数值 |
| \<random:value \*\[表达式] \*\[表达式]> | 获取公式最小值\~最大值的随机值 | 数值 |

## 支持类型

* [x] INIT
* [x] SYSYEM
* [x] DUNGEON
* [x] PLAYER
* [x] SELF
