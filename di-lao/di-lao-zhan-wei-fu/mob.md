# Mob ( ! INIT )

## 占位符介绍

用于获取已击杀的怪物数量或判断是否已击杀某一种怪物

## 占位符列表

| 占位符                       | 说明            | 返回           |
| ------------------------- | ------------- | ------------ |
| \<mob:kil-amount \*怪物名>   | 获取已击杀的怪物数量    | 数量           |
| \<mob:kill-contain \*怪物名> | 判断是否是否已击杀过该怪物 | true / false |

## 支持类型

* [ ] INIT
* [x] SYSYEM
* [x] DUNGEON
* [x] PLAYER
* [x] SELF
