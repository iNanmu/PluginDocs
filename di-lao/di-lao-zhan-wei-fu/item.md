# Item ( ! INIT )

## 占位符介绍

用于 **检测地牢内玩家** 或 **触发者(@self)** 是否拥有某一件物品，并是否扣除对应数量物品

## 占位符列表

| 占位符                                                         | 说明                | 返回           |
| ----------------------------------------------------------- | ----------------- | ------------ |
| \<item:物品名 \*数量 \*是否扣除 \*过滤颜色(def:true) \*仅检测队长(def:false)> | 判断背包是否存在某个物品并是否扣除 | true / false |

## 支持类型

* [ ] INIT
* [x] SYSYEM
* [x] DUNGEON
* [x] PLAYER
* [x] SELF
