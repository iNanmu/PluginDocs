# Area ( ! INIT )

## 占位符介绍

获取地牢区域内的某些信息

## 占位符列表

**怪物匹配名：**&#x533A;域内满足名字要求的才算有效数量，默认为区域内所有怪物，模糊匹配怪物名

| area:player-size \*区域名 \*怪物匹配名  | 获取区域内的玩家数量    | 玩家数量 |
| ------------------------------- | ------------- | ---- |
| area:monster-size \*区域名 \*怪物匹配名 | 获取区域内所剩余的怪物数量 | 怪物数量 |

## 支持类型

* [ ] INIT
* [x] SYSYEM
* [x] DUNGEON
* [x] PLAYER
* [x] SELF
