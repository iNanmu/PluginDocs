# Data ( ALL )

## 占位符介绍

用于获取使用 Data 脚本所储存的数据值

## 占位符列表

| 占位符                    | 说明              | 返回           |
| ---------------------- | --------------- | ------------ |
| \<data:value \*数据名>    | 获取某个数据名上的数量值    | 数量           |
| \<data:list \*数据名 \*值> | 判断某个数据名上是否包含某个值 | true / false |

## 支持类型

* [x] INIT
* [x] SYSYEM
* [x] DUNGEON
* [x] PLAYER
* [x] SELF
