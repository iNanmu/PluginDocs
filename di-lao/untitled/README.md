# 地牢脚本

## ActionScript 是干什么的？

在地牢内所触发、处理的所有内容都靠 **ActionScript** 来完成，不管是地牢任务、地牢交互还是脚本组都离不开 **ActionScript**\
\
脚本格式为 **"$脚本名{参数=值;...} @脚本类型"**

## 我能自定义 ActionScript 脚本吗？

当然可以，但你需要掌握 Java 或 Kotlin 其中一门语言，这样子你可以靠着 DungeonPlus 所提供的 API (BasicActionScript) 来注册你的脚本
