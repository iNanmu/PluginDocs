# Obstacle

## 脚本参数

标注 **\*** 为必填参数，带有 **\*N** 为支持 英文逗号隔开多个

| 参数           | 说明                                                  |
| ------------ | --------------------------------------------------- |
| group **\*** | 地牢障碍组名称 **\*N**                                     |
| repeat \*    | 单局地牢内 **重复清除** 障碍组时是否执行 \[**障碍组触发时执行**] 脚本          |
| operation \* | 操作 **delete(清除) / undelete(恢复)** #只有清除过的障碍组执行恢复才会生效 |

## 脚本类型

**all** 代表所有的脚本类型都支持

| 类型      | 说明    |
| ------- | ----- |
| dungeon | 由地牢执行 |

## 示例

```yaml
$obstacle{group=障碍物名;repeat=false;operation=delete} @dungeon
```
