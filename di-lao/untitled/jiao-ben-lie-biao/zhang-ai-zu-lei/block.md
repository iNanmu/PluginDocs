# Block

## 脚本参数

标注 **\*** 为必填参数，带有 **\*N** 为支持 英文逗号隔开多个

| 参数          | 说明          |
| ----------- | ----------- |
| name **\*** | 所属障碍组名      |
| start \*    | 起始点\[X,Y,Z] |
| end \*      | 结束点\[X,Y,Z] |

## 脚本类型

**all** 代表所有的脚本类型都支持

| 类型      | 说明    |
| ------- | ----- |
| dungeon | 由地牢执行 |

## 示例

```yaml
$block{name=障碍组名;start=区域1;end=区域2} @dungeon
```

## 特别说明

这个脚本手动配置会比较麻烦，可以使用插件的在线编辑功能进行快捷设置，具体查看 **地牢编辑** 章节
