# SetMap

## 脚本参数

标注 **\*** 为必填参数，带有 **\*N** 为支持 英文逗号隔开多个

| 参数         | 说明                        |
| ---------- | ------------------------- |
| map **\*** | 地牢地图 **(map 文件夹内地图文件夹名)** |

## 脚本类型

**all** 代表所有的脚本类型都支持

| 类型   | 说明      |
| ---- | ------- |
| init | 地牢启动时执行 |

## 示例

```yaml
$setmap{name=地牢地图} @init
```
