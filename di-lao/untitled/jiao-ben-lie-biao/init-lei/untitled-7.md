# SetSpawn

## 脚本参数

标注 **\*** 为必填参数，带有 **\*N** 为支持 英文逗号隔开多个

| 参数              | 说明            |
| --------------- | ------------- |
| location **\*** | 地牢出生点 (X,Y,Z) |
| yaw             | 视角朝向          |
| pitch           | 俯仰角朝向         |

## 脚本类型

**all** 代表所有的脚本类型都支持

| 类型      | 说明         |
| ------- | ---------- |
| init    | 地牢启动时初始化执行 |
| dungeon | 有地牢执行      |

## 示例

```yaml
$setspawn{location=x,y,z} @init
```
