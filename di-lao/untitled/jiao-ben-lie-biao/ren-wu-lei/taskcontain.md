# TaskContain

## 脚本参数

标注 **\*** 为必填参数，带有 **\*N** 为支持 英文逗号隔开多个

| 参数          | 说明  |
| ----------- | --- |
| name **\*** | 任务名 |

## 脚本类型

**all** 代表所有的脚本类型都支持

| 类型     | 说明      |
| ------ | ------- |
| system | 由插件系统执行 |

## 示例

```yaml
$taskcontain{name=任务名} @system
```
