# Message

## 脚本参数

标注 **\*** 为必填参数，带有 **\*N** 为支持 英文逗号隔开多个

| 参数          | 说明                           |
| ----------- | ---------------------------- |
| type **\*** | 消息类型 **(text/title)**        |
| text \*     | 消息内容 ( **title 时可用英文逗号隔开** ) |

## 脚本类型

**all** 代表所有的脚本类型都支持

| 类型  | 说明     |
| --- | ------ |
| all | 发送一条消息 |

## 示例

```yaml
$message{type=text;text=内容} @dungeon
```
