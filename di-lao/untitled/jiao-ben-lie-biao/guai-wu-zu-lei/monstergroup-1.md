# Remove-MonsterGroup

## 脚本参数

标注 **\*** 为必填参数，带有 **\*N** 为支持 英文逗号隔开多个

| 参数            | 说明                                               |
| ------------- | ------------------------------------------------ |
| group **\*N** | <p>地牢内所设的怪物组名称</p><p>(可用 ',' 隔开多个组,或ALL代表所有)</p> |

**仅清除已启动的怪物组监听数据,并不会清除已生成的怪物**

## 脚本类型

**all** 代表所有的脚本类型都支持

| 类型      | 说明    |
| ------- | ----- |
| dungeon | 由地牢执行 |

## 示例

```yaml
$remove-monstergroup{group=ALL/指定名} @dungeon
```
