# Kether

## 脚本参数

标注 **\*** 为必填参数，带有 **\*N** 为支持 英文逗号隔开多个

| 参数           | 说明            |
| ------------ | ------------- |
| group **\*** | 脚本组名称 **\*N** |

## 脚本类型

**all** 代表所有的脚本类型都支持

| 类型      | 说明     |
| ------- | ------ |
| dungeon | 由地牢触发  |
| self    | 由触发者触发 |

## 示例

```yaml
$kether{group=脚本组,...} @dungeon
```
