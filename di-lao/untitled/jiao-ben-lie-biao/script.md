# Script

## 脚本参数

标注 **\*** 为必填参数，带有 **\*N** 为支持 英文逗号隔开多个

| 参数            | 说明            |
| ------------- | ------------- |
| script **\*** | 脚本组名称 **\*N** |

## 脚本类型

**all** 代表所有的脚本类型都支持

| 类型      | 说明                     |
| ------- | ---------------------- |
| dungeon | 由地牢触发 (无触发者对象)         |
| player  | 由地牢内每位玩家为触发者(每个玩家触发一次) |
| self    | 由触发者触发                 |

## 示例

```yaml
$script{script=脚本组,...} @player
```
