# Team-Condition

## 脚本参数

标注 **\*** 为必填参数，带有 **\*N** 为支持 英文逗号隔开多个

| 参数          | 说明                              |
| ----------- | ------------------------------- |
| team **\*** | 是否需要组队 **(true/false)**         |
| message \*  | 不通过时全队提示  **( \<size> 为队伍人数 )** |
| min         | 队伍下限人数                          |
| max         | 队伍上限人数                          |

## 脚本类型

**all** 代表所有的脚本类型都支持

| 类型     | 说明      |
| ------ | ------- |
| system | 由插件系统执行 |

## 示例

```yaml
team-condition{team=true;min=3;max=5;message=队伍必须3人以上才可挑战,当前队伍人数 (<size>)} @system
```
