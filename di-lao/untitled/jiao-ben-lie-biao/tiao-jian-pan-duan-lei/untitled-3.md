# Data-Condition

## 脚本参数

标注 **\*** 为必填参数，带有 **\*N** 为支持 英文逗号隔开多个

| 参数         | 说明                                                          |
| ---------- | ----------------------------------------------------------- |
| key **\*** | 数据名                                                         |
| type \*    | 数据类型 **value(数值) / list(列表)**                               |
| value \*   | value 时可使用运算符号,例如 **>10**                                   |
|            | list 时 **"怪物"** 则数据内包含怪物则满足,带上 **!** 符号则不包含时满足,例如 **"!怪物"** |

## 脚本类型

**all** 代表所有的脚本类型都支持

| 类型     | 说明      |
| ------ | ------- |
| system | 由插件系统执行 |

## 示例

```yaml
$data-condition{key=数据键;type=<value/list>;value=>10} @system
```
