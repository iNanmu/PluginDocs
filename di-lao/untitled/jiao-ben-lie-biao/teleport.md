# Teleport

## 脚本参数

标注 **\*** 为必填参数，带有 **\*N** 为支持 英文逗号隔开多个

| 参数                      | 说明                  |
| ----------------------- | ------------------- |
| location **\***         | 传送位置\[X,Y,Z]        |
| yaw                     | 视角朝向                |
| pitch                   | 俯仰角朝向               |
| defspawn (default:true) | 全队传送时将传送点设置为副本默认重生点 |

## 脚本类型

**all** 代表所有的脚本类型都支持

| 类型             | 说明         |
| -------------- | ---------- |
| dungeon、player | 由地牢内所有玩家触发 |
| self           | 由触发者触发     |

## 示例

```yaml
$teleport{location=X,Y,Z} @player
```
