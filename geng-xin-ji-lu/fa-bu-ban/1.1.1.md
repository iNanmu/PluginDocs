# 1.1.1

## 更新内容

* 重构 **Taboolib 5** -> **6**
* 兼容 从该版本开始支持 Minecraft **1.17.X** 版本
* 兼容 新版地牢跨服附属 (**DungeonPlus-BungeeCord**)<br>
* 新增 [**Placeholder** ](https://ersha.gitbook.io/dungeonplus/di-lao/di-lao-zhan-wei-fu/random)地牢占位符,具体效果请查看对应WIKI页面
* 新增 地牢物品右键使用&抛射类型限制 **(CONFIG.YML)**
* 新增 地牢名加载限制 (因为高版本不支持中文地图名/该版本起 **只支持英文地牢名** )<br>
* 修复 **1.16.5** 版本书本界面异常问题
* 修复 **TELEPORT** 脚本会将死亡玩家复活问题
* 修复 修复在 **PAPER** 核心可能出现的登录报错问题
* 修复 **MESSAGE** 脚本使用 **TITLE** 类型时可能失效的问题
* 修复 队长可在地牢同意他人入队申请问题<br>
* 调整 从该版本起地牢内将无法执行队伍操作

{% hint style="info" %}
更新至 **1.1.1** 请将旧版 **lang** 文件夹删除重新生成
{% endhint %}
