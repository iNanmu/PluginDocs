# 1.0.8

## 更新内容

* 新增 **地牢占位符** 组件
  * dungeon / mob / if / item / data
  * 具体占位符详细作用请前往 [地牢占位符](https://ersha.gitbook.io/dungeonplus/di-lao/di-lao-zhan-wei-fu) WIKI页面
* 新增 地牢挑战启动 **参数&占位符**
  * \<dungeon:params \*参数位 \*默认值>  启动参数地牢占位符<br>
* 新增 地牢挑战等待 **队列** 功能 (配置项请查看 [CONFIG.YML](https://ersha.gitbook.io/dungeonplus/cha-jian-pei-zhi))
* 新增 **CONFIG.YML** 配置自动更新功能
* 新增 **DP PLACEHOLDER** 命令,可获取服务器已加载的地牢占位符列表
* 修复 Paper 核心高版本进入地牢后飞行模式不会自动关闭问题<br>
* 调整 地牢启动命令权限调整为 **dungeon.user** -> **dungeon.start**
  * 挑战命令挑战 /dp start <地牢> **<参数1;参数2;...>**
  * 启动参数详细内容请查看 [地牢启动参数](https://ersha.gitbook.io/dungeonplus/di-lao/di-lao-jie-shao/di-lao-qi-dong-can-shu) WIKI页面
