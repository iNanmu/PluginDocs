# 1.4.2

## 更新内容

可能有部分小变动未记录，但最主要的新增、修复、优化记录都在下方

* 新增 **1.20.1、1.20.4** 服务器版本兼容
  * ```yaml
    高版本用户建议将 dungeon-pre-folder 预加载世界缓存功能开启，能避免频繁加载世界
    区块所带来的消耗，导致副本启动耗时;

    开启该功能将因为世界缓存额外占用部分内存，本地测试时开启预加载缓存 30 个世界，比没
    开启该功能额外消耗 50MB 左右内存，回报率极高;

    功能开启后经过缓存的副本，能做到玩家秒开副本，相关功能在 1.3.8~1.3.9 更新记录有相
    关介绍; #高版本没开该功能重复开本每次都慢的跟坨屎一样#
    ```
* 新增 PlaeholderAPI 部分变量
  * ```yaml
    新增 %dungeon_data_<数据名#默认值>% 快速获取玩家当前地牢Data存储器数据
    新增 %dungeon_area_name% 获取玩家所处地牢区域名
    ```
* 新增 Remove-MonsterGroup 清除已开启的怪物组脚本
  * ```yaml
    仅清除已启动的怪物组监听数据,并不会清除已生成的怪物
    $remove-monstergroup{group=ALL/怪物组名} @dungeon
    ```
* 新增 Kill-Any 怪物数量击杀条件脚本
  * ```yaml
    判断地牢内击杀列表内任意怪物数量的合达到一定数量
    $kill-any{mobname=怪物A,怪物B;amount=击杀数量} @system
    ```
*   新增&调整 Task 地牢任务脚本

    * ```yaml
      调整任务类型为TIMING的地牢任务最终运行处理，当任务执行完最后一阶段任务自动结束任务

      新增 operation 参数 restart 重启操作类型
      $task{name=任务名;operation=restart;mode=timing;async=true} @dungeon
      ```
