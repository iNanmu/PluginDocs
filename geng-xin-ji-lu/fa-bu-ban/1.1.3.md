# 1.1.3

## 更新内容

* 重写 **地牢队伍** 功能模块 \
  &#x20;        原类 **DungeonGroup** -> **Team**\
  &#x20;        管理器 **GroupManager** -> **TeamManager**\
  &#x20;        新命令 **transfer**(队长转让) **request**(入队申请) 其余命令无变动
* 重写 **区域** 范围判断、**障碍物区域** 方块读取 \
  &#x20;        更少的消耗，效率更快<br>
* 修复 旧版本可能因为 **区域过大造成的内存溢出** 问题&#x20;
* 修复 恢复障碍物区域内部分 **方块数据、朝向不准确** 的问题 \
  &#x20;        例如 半阶梯、阶梯、头颅 等物品方块，不再出现**生成朝向错误**，**子类型丢失**问题&#x20;
* 修复 1.1.2 版本玩家在地牢可能出现 **点击无法复活** 问题

{% hint style="info" %}
更新至 1.1.3 版本建议将 LANG 文件夹内容删除重新生成，避免新版组队提示错误
{% endhint %}
