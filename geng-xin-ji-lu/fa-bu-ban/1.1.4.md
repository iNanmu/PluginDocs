# 1.1.4

## 更新内容

* 新增 [**地牢区域**](../../di-lao/di-lao-qu-yu.md) 功能
* 新增 内置 [**地牢全息交互**](https://ersha.gitbook.io/dungeonplus/kai-fa-zan-zhu-ji-hua/cha-jian-fu-shu/di-lao-quan-xi-jiao-hu) 功能 ( 需 **HolographicDisplays** 插件支持 )
* 新增 脚本 [**触发地牢区域**](../../di-lao/untitled/qu-yu-xian-zhi.md) 要求 ( 在区域内的玩家才会触发脚本效果 )
* 新增 [**AREA**](../../di-lao/di-lao-jiao-hu-jiao-ben-dungeoninteract/area.md) 地牢交互脚本类型 ( 进入地牢区域时触发,区域内的玩家为触发者 )
* 新增 [**SELF** ](../../di-lao/di-lao-zhan-wei-fu/self-self.md)触发者地牢占位符
  * \<SELF:PLAYER-NAME> 获取玩家名
  * \<SELF:AREA-NAME> 获取玩家所在地牢区域名
*   新增 [**AREA** ](../../di-lao/di-lao-zhan-wei-fu/area-init.md)地牢区域占位符

    * \<AREA:PLAYER-SIZE \*区域名> 获取区域内的玩家数量


* 重写 地牢脚本读取即触发执行代码 ( 处理效率 **更快** 兼容性 **更好**  开发者 **更&#x20;**<mark style="color:red;">**爱**</mark>**&#x20;我** )
*   重写 怪物组怪物击杀数据处理

    &#x20;        怪物组条件达成自动扣除相对应怪物的击杀数量数据 ( 用KILL脚本的情况下 )


* 修复 在脚本执行时发送错误导致整个脚本执行中止问题
