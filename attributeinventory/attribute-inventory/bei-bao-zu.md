# 背包组

## 介绍

每个背包组可自定义不同的数量的 **装备页、装备槽、套装** 等数据，支持翻页，并且支持多页属性生效

## 基础配置介绍

背包组均以以下配置项组成 **自定义槽位、权限、页面权限** 等

```yaml
#背包组名
#使用 /ai open 符石背包组 可打开该背包组
content-name: "符石背包组"
#背包组打开权限
#删除该项则无需权限即可打开该背包组
content-permission: "符石背包组"

#启用套装
#这里配置的套装名后需要再 suit 文件夹内配置对应的套装数据
enable-suits:
  - "符石套装"

#装备页布局
pages:
  1:
    #该页装备页的标题
    title: "第一页"
    #该页装备页的布局 (布局材料为 materials 内所设)
    layout:
      - "#########"
      - "###A#B###"
      - "##∧###∨##"
    #打开该页面的条件,支持 Kether 语法 (该项可选)
    #condition:
    #  - "check '%player_level%' >= 10 # 你的等级需要达到 10 级才可以翻页"
  #可设置多页
  2:
    ...

#布局材料及槽位 (这里先省略,下面会介绍该部分的配置)
materials: ...
```

## 装备槽的定义

背包组内的装备槽配置均在 materials 配置项上，这里可以设置 **允许放入的装备、放入的条件** 等数据

```yaml
#布局材料及槽位
materials:
  "A":
    #布局材料显示类型
    material: YELLOW_STAINED_GLASS_PANE
    #布局材料显示名
    name: "§6橙色符石槽"
    #布局材料显示描述
    lore:
      - "§f请放入对应符石装备"
    #当布局材料内包含 equipment 配置项数据
    #该布局材料即为一个装备槽,玩家可放置符合条件的装备
    #如果没有这项配置,那该布局材料仅用于布局展示
    equipment:
      #装备唯一ID,同个装备页配置内不要相同
      id: "橙色符石槽"
      #即装备描述包含匹配的描述即可放入槽位内 (模糊匹配不过滤颜色代码)
      type: "§6橙色符石"
      #条件判断,支持 Kether 语法 (可选)
      #condition:
      #  - "check '%player_level%' >= 10 # 你的等级需要达到 10 级才可使用该槽位"
  "B":
    ...
  "C":
    ...
  "D":
    ...

  #翻页按钮固定为 ∧ ∨ 字符,不可占用修改
  "∧":
    material: PAPER
    name: "§f上一页"
  "∨":
    material: PAPER
    name: "§f下一页"
```

## 启动套装

当你配置好一个套装配置并配置完一个背包组后，你想要该背包组启用某个套装组，你可以这样做

```yaml
#启用套装
#这里配置的套装名后需要再 suit 文件夹内配置对应的套装数据
enable-suits:
  #在这里添加你所配置的套装名
  - "符石套装"
```
