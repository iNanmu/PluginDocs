# Random

{% tabs %}
{% tab title="整数随机" %}
> 占位符格式

```yaml
{random *r:最小值-最大值 *评分}
```



> 占位符用法

随机整数并最终以 **随机值\*评分** 来增加制作物的评分，每触发一次这个占位符都会加一次
{% endtab %}

{% tab title="浮点数随机" %}
> 占位符格式

```yaml
{random *r:最小值(0.0)-最大值(1.0) *评分}
```



> 占位符用法

随机浮点数并最终以 **随机值\*评分** 来增加制作物的评分，每触发一次这个占位符都会加一次
{% endtab %}

{% tab title="文本随机" %}
> 占位符格式

```yaml
{random *rs:[文本,文本,...] *[评分,评分,...]}
```



> 占位符用法

随机出一个文本并获取对应的 **评分** 增加至锻造物评分上，每触发一次增加一次
{% endtab %}
{% endtabs %}
