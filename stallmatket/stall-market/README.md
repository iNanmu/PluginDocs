# 📦 Stall Market

## 介绍

基于 **Kotlin / Taboolib** 开发的自定义摆摊+全球市场插件，该插件采纳了摆摊及全球市场的优点结合

:smile: 插件视频 [https://www.bilibili.com/video/BV1KG411J7e4/](https://www.bilibili.com/video/BV1KG411J7e4/) (所见即所得)

:tada: 已完成功能

* 离线摆摊功能 (抛弃传统玩家罚站摆摊)
* 摆摊区域功能 (限制在某些世界某些区域才能摆摊)
* 发包摊位实体 (采用实体发包减轻服务器负担)
* 摊位市场功能 (让服务器摊位一览无余)
* 摊位筛选功能 (让玩家快速筛选所需物品的摊位)
* 出售/收购双模式 (摊位可同时存在两种类型的商品)
* 自定义交易货币 (支持摊主设置 **以物换物** 货币)
* 自定义摊位等级 (可设置不同等级摊位上架商品数量限制)
* 自定义摊位模型 (可根据摊位等级设置不同模型)
* 自定义摊位税收 (可根据摊位等级设置不同税收，不同货币可设置不同税率)
* 自定义禁止上架物品 (通过模糊匹配物品名、物品描述进行限制)
* 支持商品NBT储存 (模组、特殊物品均可)
* 支持本地/数据库储存 (数据库多服实时同步)

:clap: 待开发功能

* Decent Holograms 全息插件兼容 (摊位商品物品轮播，摊主留言功能)
* 摊位皮肤库 (不同摊位不同模型，实体类型等)
* 摊位租赁功能
* 更多插件兼容
