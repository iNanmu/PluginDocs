# 💎 Item Extension

## 介绍

基于 **Kotlin / Taboolib** 开发的装备扩展功能，可以做到 **装备赋能、装备附魔、装备宝石** 等玩法

扩展道具可为装备扩展上 **SkillAPI MythicMobs Planners** 技能，同时有配有 **套装** 功能

相比市面上相类似的装备扩展插件，用 **ItemExtension** 能做的更好<br>

:smile: 插件视频 [https://www.bilibili.com/video/BV1v54y1K7gi](https://www.bilibili.com/video/BV1v54y1K7gi)

:tada: 已完成功能

* 自定义扩展道具 **属性** 效果
  * AttributePlus、SX-Attribute、AttributeSystem `(2.X~3.X均支持)`
  * 未来将根据需求支持更多属性插件的兼容
* 自定义扩展道具 **技能** 效果
  * 支持 `SkillAPI、MythicMobs、Planners` 插件技能
  * 为你服务器的稀有装备扩展上独有的技能
  * 拥有数多种技能触发器供你选择
* 自定义扩展道具 **套装** 效果
  * 根据玩家身上所有装备所扩展的道具数量，激活不同的套装效果
  * 激活套装后可为玩家额外增加 `属性、技能` 效果
* 自定义 **镶嵌/拆除** 扩展道具时触发 **Kether** 语法
  * 同时提供如 `物品名、类型、附魔、NBT` 数据进行操作的 `Kether` 私有语法
  * 可对修改的数据进行 `恢复、删除` 操作
* 自定义扩展界面，支持 **翻页** 操作
  * 你可以设置每个位置仅允许放置某一种 `扩展位识别符` 放置

:tada: 插件兼容

* AttributeInventory (属性背包)
* DragonCore (龙核)  /  GermPlugin (萌芽)
* 提供[ API ](kai-fa-wen-dang.md)供开发者兼容

:clap: 插件特色

* 可以多个并且不同的扩展位设置在同一行描述上 (相关传统插件无法做到)
* 能够完美的释放 `SkillAPI、MythiMobs、Planners` 插件技能
* ~~楠木的气味加成，能够使你充满楠木的味道~~
