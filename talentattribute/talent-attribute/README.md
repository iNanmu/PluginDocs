# 📕 Talent Attribute

## 介绍

一个基于 **Kotlin / Taboolib** 开发的自定义天赋加点插件，可设置多个天赋界面，每个天赋界面内的 **天赋页布局可完全自定义**、**天赋页支持翻页**、**天赋页打开条件(包括翻页)**、**天赋项洗点** 等操作，支持 **自定义不同类型的天赋点** 数据储存方式支持 **数据库、本地储存**\
\
:clap: 支持的属性

* AttributePlus
* SX-Attribute
* PxRPG
* OriginAttribute
* Custom Attribute API (自定义)
