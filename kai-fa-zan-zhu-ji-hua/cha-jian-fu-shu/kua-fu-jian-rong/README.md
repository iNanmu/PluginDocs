# BC 跨服兼容

## 跨服兼容

可以让可以在 **BungeeCord** 大厅选择地牢进行挑战，挑战时玩家队伍将被传送至对应的子服进行对应的地牢挑战，对中大型的RPG服务器有很大的帮助，挑战结束后玩家将被传送回开启挑战时的大厅

该功能需要再 **BungeeCord** 服务器安装 **DungeonPlus-BungeeCord** 附属插件，该附属插件目前仅提供参与**开发赞助计划** 的用户
