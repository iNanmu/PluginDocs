# UI 组队界面

## UI组队界面

显示的组队操作界面，入队申请界面、服务器队伍列表界面，支持 **龙核、萌芽(17 暂未兼容)** 插件，提供同款贴图，需要安装对应的前置插件，插件命令 **DPTV OPEN** 打开界面 / **DPTV RELOAD** 重载
