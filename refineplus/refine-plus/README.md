# 🔮 Refine Plus

## 前言

**RefinePlus** 是一款物品洗练插件，通过洗练修改物品描述，配合其他属性插件做到属性洗练效果，同时可以设置 **保护符道具、几率提升道具、洗练强度增幅道具、属性条目道具** 等道具，洗练属性值全使用 **公式计算**，洗练时 **可锁词条** (锁定的词条将不会被洗练掉)，可自定义洗练的词条强度颜色，全服提醒等设置，可设置 **多个不同的洗练界面(布局完全自定义)** 插件理论支持 **1.8\~1.17** 版本，开发测试为 1.12.2 版本

## 插件基础配置

```yaml
options:
  #插件授权码
  code: "授权码"
  #语言文件
  lang: "zh_CN.yml"

#洗练词条强度符号&颜色 (1~100%)
refine-intensity:
  #强度颜色，强度颜色区间 (100/颜色个数)
  #例子: 当洗练词条强度大于 80 小于 90 则为 &6 橙色
  color: "F73BA2E6C4"
  #符号
  symbol: "★"

#洗练信息
refine-info:
  #顶部描述 (不可为空白)
  top: "&f&m&l--------&f[&6&l洗练属性&f]&f&m&l--------"
  #底部描述 (可以为空白)
  bottom: "&f&m&l--------&f[&6&l洗练属性&f]&f&m&l--------"
```
