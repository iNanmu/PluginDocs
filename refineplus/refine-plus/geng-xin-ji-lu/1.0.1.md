# 1.0.1

## 更新记录

* 新增 洗练道具使用限制条件新增物品名判断
* 新增 洗练完毕后以OP权限执行设置的命令
*   新增 洗练项目内公式支持 **PlaceholderAPI** 变量


* 调整 插件硬性前置新增 **PlaceholderAPI** 插件 (服务器必备插件)
*   调整 洗练词条强度全服提醒功能 (洗练后词条强度大于时触发)

    * remind: **true/false** -> remind: **1\~100**


* 修复 属性词条出现条件中 **洗练次数要求** 失效问题
* 修复 放入多个材料重复扣材料数量问题
* 修复 洗练项目是否允许锁词条洗练配置失效问题

{% hint style="info" %}
目前插件已基本稳定，支持 **AttributePlus / SX-Attribute** 等通过 **物品LORE** 增加属性的所有属性插件，快找 **投喂楠木** 吧！
{% endhint %}
